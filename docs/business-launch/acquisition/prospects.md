# Prospect List — First Outreach Batch

Work package D/E of [#113](https://github.com/WintCom-Solutions/wintersoperations-site/issues/113),
built for [#116](https://github.com/WintCom-Solutions/wintersoperations-site/issues/116).

Six public MSP/IT-services businesses, prioritized by distance from Hernando,
MS: Hernando first, then DeSoto County/Southaven/Olive Branch, then Memphis
metro. All information below comes from each business's own public website
or public directory listings (BBB, chamber-of-commerce member pages, Yelp) —
**no private contacts, personal emails, or non-public information are
included.** Sources and access dates are cited per prospect; check dates are
2026-09-15.

**Important framing — read before using these:** none of these openers or
fit notes assert that a prospect needs a subcontractor or has a documentation
backlog. Every "fit evidence" line is a public-record observation (services
offered, project types, service-area breadth) that makes the $0 pilot offer
*plausibly relevant* — not a claim about their internal operations, staffing,
or need. Each opener asks rather than assumes, per parent issue #113's
explicit instruction not to assume subcontractor need.

The pilot offer referenced throughout is **Network Documentation Cleanup —
$75 flat**, from [`../sales-kit/offers-and-service-descriptions.md`](../sales-kit/offers-and-service-descriptions.md).
No price is publicly committed by this document; Karl confirms before any
message is sent (see that file's kit README).
